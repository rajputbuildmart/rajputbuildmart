# Rajput Buildmart — Deployment Notes

This package is a static, production-ready site. The public-facing pages contain no internal build instructions or placeholder catalogue messaging.

## Quick publish
1. Unzip the package.
2. Publish the contents of `rajput-buildmart file/` as the site root.
3. The site entry point is `index.html`.

Netlify supports drag-and-drop publishing of a project folder. For this package, use the unzipped site folder as the deploy directory.

## Before connecting a custom domain
- Confirm the business phone, address, opening hours and social links.
- Add the final production domain to canonical/OG/sitemap metadata if a custom-domain SEO setup is desired.
- Submit the final sitemap in Google Search Console after the domain is live.
