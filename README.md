# RAJPUT BUILDMART — Production Website Package

Static multi-page website for Rajput Buildmart, Kolar, Bhopal.

## Included
- Responsive premium website across Home, About, Products, category pages, Brands, Catalogues, Professionals, Project Support and Contact.
- User-supplied premium showroom image integrated into the Home hero.
- 8 supplied product catalogues placed under `assets/catalogues/` with cover previews and direct View PDF / Download actions.
- Responsive catalogue search and category filters.
- SEO basics: descriptive titles, meta descriptions, robots directives, favicon, LocalBusiness structured data already present in the site, and a custom 404 page.
- `DEPLOYMENT.md` contains private deployment notes; it is not part of the public UI.

## Catalogue library
- Eva Shine
- Plasto
- Astral
- Somany Bathware
- Rivera
- R Ceramica
- Rivo Cera
- Sparsh Pearl

## Deploy
Publish the contents of this folder as the website root. `index.html` is the entry page.
